SKMedKART V5.9.25 FINAL SAFE FIX

This package keeps the existing app and data locally and disables live Firebase sync to prevent quota errors from affecting billing/returns.

Fixes included:
1. Return Bill works from local saved data without Firebase quota errors.
2. Batch Alerts no longer shows OUT OF STOCK for a medicine when any matching available batch has stock > 0, including duplicate product records with the same medicine name.
3. Existing invoice PDF assets/layout are preserved.
4. No other feature changes are intended.

MULTIPLE MEDICINES IN ONE BILL - FIXED

How to use:
1. Enter customer details once.
2. Select Medicine 1, Batch 1, Qty, Rate.
3. Tap “Add to This Bill”.
4. The medicine fields clear automatically.
5. Select Medicine 2 and tap “Add to This Bill”.
6. Repeat for Medicine 3 or more.
7. All added medicines remain in the same bill list.
8. Tap “Save Bill & Reduce Stock” only once.
9. One invoice is created containing all medicines.

Stock reduction is applied batch-wise for every item in the single bill.
